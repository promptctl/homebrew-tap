# promptctl/tap

Homebrew casks for [promptctl](https://github.com/promptctl) tools.

```sh
brew install --cask promptctl/tap/vhid
brew install --cask promptctl/tap/low-talker
```

| cask | what it installs |
|---|---|
| [low-talker](Casks/low-talker.rb) | [LowTalker](https://github.com/promptctl/low-talker): push-to-talk dictation that runs entirely on your Mac |
| [vhid](Casks/vhid.rb) | [vhid](https://github.com/promptctl/vhid): a virtual keyboard and mouse for macOS, driven from a CLI or over MCP |
